    Field Reporting Hub

    This hub connects field updates to your Google Sheets (Monitoring & Evaluation), then refreshes the dashboard. It can also send the submitted update to the AI Assistant to produce an instant summary, risks, and recommendations.

    How it works
    1. Fill a short field update (Monitoring or Evaluation).
    2. Submit to Sheets (via Apps Script Web App endpoint).
    3. Dashboard auto-refreshes Monitoring/Evaluation tables and KPIs.
    4. Optional: send the same content to AI for instant analysis/report drafting.
    Note: To fully enable submission, paste your Apps Script Web App URLs into the config constants in the JavaScript section. If left blank, the hub will run in Demo mode (no network write).
